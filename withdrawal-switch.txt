# NetDiag withdrawal switch
#
# The app reads this file once when it opens, and reads nothing else that happens on its own.
# The first line decides: `off` retires the build, anything else runs it.
#
# on   - the app works. This is the normal state.
# off  - the app stops at launch and says so, naming the build it is refusing to run.
#
# To retire a test build, change the line to `off`, optionally rewrite `message`, commit to the
# default branch, and every copy that opens afterwards stops. No new APK, no server, no push
# notification to anybody.
#
# The reason it fails open - and it does, always - is that this file cannot be allowed to strand
# somebody. No network, a timeout, a 404, a login portal answering instead, a typo: the app runs.
# So it can retire a version, and it cannot enforce anything against a device that is offline.
#
# Two things to know before you flip it, because neither is instant and both are by design:
#   - GitHub's raw host serves this file from a cache for a few minutes after a commit, so a copy
#     of the app opened straight away can still read the old line.
#   - The app asks once when it opens and never again, so an app already open on somebody's phone
#     keeps working until they close it and start it once more.
